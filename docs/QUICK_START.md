# PoE2Mouse v0.1.15 快速开始
这是工程测试版，尚未验证 PoE2 游戏兼容性。不需要安装 Python 或编译工具。
 
1. 解压整个 Windows x64 包至独立目录，例如 D:\Games\PoE2Mouse。
2. 双击 input_bridge.exe（主程序）。即使缺少驱动或 DLL，仍可打开中文界面。device_probe.exe 与 input_lab.exe 是可选诊断工具。
3. 点击【新手引导 / 下一步】；第一步无需驱动，先按提示验证离线预览。按【检查依赖】提示准备可信 x64 ViGEmClient.dll 与官方 ViGEmBus 驱动（已停止维护，用户自行决定安装；本程序不自动安装）。详细来源见 DEVICE_PROBE.md。
4. 【检查依赖】仅加载 SDK 并连接/关闭驱动会话，不创建设备；通过后【连接两个设备】。默认暂停。
5. 【中文键位 / 改键】读取当前实际配置。关闭游戏后，在 Windows 游戏控制器（Win+R → joy.cpl）中检查两个设备；按 BRIDGE_TEST.md 验证单个按键和释放。不要把诊断映射当作已验证的 PoE2 技能栏。
6. 【暂停输出】保持设备连接、归零；【断开设备】尝试释放设备而不退出软件。恢复单人游戏模式仍需游戏内操作。
7. 遇到问题点【复制诊断】，粘贴到 ChatGPT 对话或 https://github.com/jkszz231210-ops/poe2mouse/issues/new，并附复现步骤及控制台错误码。无自动上传。
 
配置错误时仍可打开主界面。先备份 bridge.profile / bridge.map，再移出程序目录（不删除原文件），点击【重新读取配置】以使用随包默认文件。配置重载时暂停输出；配置不合法时不允许启用。
 
## 常见错误
E200/E201/E202：检查可信 DLL 文件名、x64 架构及 SDK 版本；E205：检查驱动安装；E206/E207：设备槽位/回读失败；E300：配置错误，点击查看当前键位获得原因；E301-E305：输入或输出异常，先暂停；E306：剪贴板失败，复制控制台内容；E307：帮助或链接打开失败，阅读本文件。未验证强制退出、市场、游戏输入切换，见 ACCEPTANCE.md。

公司电脑无游戏/驱动：主程序内点离线预览，W/P1、方向键/P2、Q/Shift+Q，观察中文动作和实际虚拟手柄控件。使用主程序的同一份配置，无真实输出。点击中文键位/改键直接保存，立即加载，无需重启，重新启用预览即可。原生快捷键与默认 F10 暂停说明见 NATIVE_UI.md。

引导最后一步可点击【设备输出自检】；关闭所有游戏并确认后，逐个测试设备固定轴值、另一设备中立及归零。无需安装游戏。它不能证明游戏兼容性。

连接两个设备后必须先关闭游戏并通过设备输出自检，才允许真实设备输入。W206 可继续自检；E206/E208 请反馈控制台。连接期间不要插拔其他控制器。

底层自检后点真实设备本窗测试，观察两个设备真实 XInput 回读及松键归零。不是离线预览，也不是游戏兼容性证明。

## 一键准备依赖（0.1.15）
主程序点击【检查依赖】，缺少 DLL 或驱动连接失败时可进入【一键准备依赖】；亦可直接点击该按钮。下载固定版本并校验，DLL 自动放到 EXE 同级，已有 DLL 不覆盖。已检测到 ViGEmBus 服务时跳过驱动下载（实际可用性仍需检查）；否则下载签名有效的官方安装包至 dependencies，输入 Y 才启动安装向导。安装后回主界面重新检查。无管理员权限或 PowerShell 执行策略阻止时，使用 DEVICE_PROBE.md 手动方式，不绕过策略。
