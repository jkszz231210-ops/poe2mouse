# v0.1.13 独立输入桥试验版（尚未实机验证）
本版本增加 input_bridge.exe，首次接通物理键鼠事件到实际虚拟设备报告的代码路径。仅支持人工一对一映射到指定角色。拒绝 both 与 solo 沙盒动作，不自动施法、不跟随、不镜像、不接管游戏内存。驱动及 DLL 由用户自行确认安装，见 DEVICE_PROBE.md。
 
## 初次测试
1. 解压完整便携包，关闭游戏。按 DEVICE_PROBE.md 先运行设备探测，确认两个 XInput 设备的回读及清理通过。
2. 运行 input_bridge.exe，先查看【新手教程】及【检查依赖】，选择可信的 x64 ViGEmClient.dll（或自行将已验证 DLL 放在 EXE 同目录，或在 PowerShell 传入 DLL 绝对路径），确认加载 SDK 后点击 连接两个设备，才创建临时设备。记下控制台显示的 P1/P2 槽位。
3. 先选择 本窗口测试。WASD 控制 P1 左摇杆，方向键控制 P2 左摇杆。Q/E/R/F/T 与鼠标左/右/中键是 P1 的测试按钮；Shift+同样的键是 P2 测试按钮。均为诊断映射，不是经过确认的 PoE2 技能槽。右摇杆默认中立，优先验证原生自动选敌；F5-F8 可人工调整右摇杆方向，Shift+F5-F8 为 P2。Enter/Backspace 对应 Start/Back，小键盘 8/2/4/6 对应 D-pad，7/9 对应左右摇杆按下（Shift 修饰为 P2，开启 NumLock）。默认映射是诊断用，旧自定义配置不自动添加这些键位。
4. 如需在 joy.cpl 中观察，选择 选择测试窗口（3秒），确认后在三秒内切到手柄属性测试窗口。每次只测试单个映射。切出指定窗口、检测到输入设备拔出或系统挂起即停止并尝试归零，需要手动重新启用。不屏蔽原生键鼠；窗口选择机制只用于允许重映射的应用。
5. 检查单按、持续按住、双键对角线、组合键先松修饰键、切换窗口、关闭程序。验证另一设备不受单次按键影响。不要把测试映射误认为 PoE2 实际槽位；游戏内是否接受虚拟设备、原生键鼠冲突仍待核实。
 
## 配置
复制 bridge.default.profile 为 bridge.profile；复制 bridge.default.map 为 bridge.map，修改后点击【重新读取配置】。软件更新不覆盖用户文件。profile 使用 Schema 3；map 每行为 p1/p2、逻辑动作、单个控制器控件。可用名称：lup/ldown/lleft/lright、rup/rdown/rleft/rright、a/b/x/y、lb/rb、lt/rt、dup/ddown/dleft/dright、start/back、lthumb/rthumb。映射缺失、重复配置、共享动作都会禁止启用输入，主界面仍可使用。可以独立按键控制肩键/扳机；不自动产生组合输出。
 
## 反馈
点击 复制诊断 复制报告（会先暂停），粘贴到 ChatGPT 或 GitHub Issue，补充现象。控制台仍提供驱动返回码。E305 输入状态容量异常，E306 剪贴板报告失败。E300 配置错误；E301 Raw Input 注册失败；E302 窗口焦点监控错误；E303 输出失败；E304 中立恢复失败（尝试关闭设备）。无自动磁盘日志或键鼠历史。暂停输出 只暂停并保留设备；断开设备 释放设备但不退出程序，Connect devices 可重新创建，需手动重新启用。回到游戏单人模式仍需通过游戏 UI 完成，是否需要退回角色界面待验证。正常退出尝试归零和释放设备，异常终止、左右同名修饰键与多键盘同键已加入状态聚合和回归用例，仍需实机验证。此版不宣称已经通过游戏内测试。

暂停时注销 Raw Input 并停止焦点计时器；重新启用时要求全部按键释放。完整验收清单见 ACCEPTANCE.md。

主程序不再因缺少 SDK 或配置错误直接退出。完整快速开始见 QUICK_START.md；查看当前键位展示实际配置（不是写死的默认表）。

主程序有同配置的离线预览与可点击引导，不再要求用独立沙盒验证主程序绑定。改键保存后即时加载，但为安全保持暂停。F10 默认暂停映射，原生界面操作说明见 NATIVE_UI.md。

【设备输出自检】可直接执行原先 device_probe 的逐设备固定轴值读回测试，必须关闭所有游戏后明确确认；不代替人工键位测试。

E206 表示槽位无效/重复；E207 表示初始中立状态无法回读。反馈控制台 P1/P2 数值、XInput 0..3 状态及返回码。枚举等待最多约 5 秒，回读有限重试；失败仍释放设备，不绕过验证。若主程序立即释放设备，可关闭主程序，按 DEVICE_PROBE.md 独立执行 device_probe.exe，在输入 TEST 前查看 joy.cpl。

PM-019：设备逐个创建，依据 XInput 新增槽位识别；请勿在连接期间插拔其他控制器。W206 表示 SDK 编号不一致，不直接判失败；必须关闭游戏并通过设备输出自检（独立样本与归零）后才允许真实输入。失败释放设备。无需重装现有可连接驱动/DLL。
