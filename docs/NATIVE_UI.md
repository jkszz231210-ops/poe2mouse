# 原生界面快捷键与输入模式（0.1.11）
用户公司实测截图发现 PM-013/014/015：文字教程不能一步步操作，英文动作/手柄控件难懂，独立沙盒配置与真实桥不同，I 等原生键可能与映射冲突。
 
## 模式边界
- 战斗映射模式：独立键鼠→虚拟手柄，原生键鼠事件始终保留，不屏蔽。默认 F10（bridge.default.options，用户可复制为 bridge.options 改成 F1-F24；VK 112-135）为停止映射的保留键，禁止与任何角色绑定冲突。仅在映射/预览启用且收到该前台键时处理。
- 原生键鼠模式：按 F10 或主界面按钮，立即尝试归零、注销 Raw Input、停止映射，保留已连接手柄。它不强制游戏切换输入模式。恢复映射需要显式重新启用目标窗口。市集/背包/聊天时先暂停；若游戏的本地合作模式拒绝原生键鼠，则需要手柄原生菜单路径或游戏退出同屏的能力，尚待实测。没有 UI 识别、没有模拟交易、没有自动快捷键序列。
- 旧配置若绑定 I 等不会自动覆盖，使用中文键位编辑器手动改键。新默认右摇杆改为 F5-F8，避免 I；实际技能槽与游戏绑定未确认。

## 验收
无游戏：离线预览、中文键位编辑、重复绑定拒绝、即时应用、F10 暂停、恢复时手动启用。游戏：双手柄识别与独立控制、暂停后原生背包/商城/地图/快捷键是否能操作、恢复映射后技能是否正确、游戏侧输入切换与市集。全部须真实客户端验证。
